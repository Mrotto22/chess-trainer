Chess Trainer (offline)

Open on a computer:
  * Double-click index.html (works straight from the folder, no internet), or
  * Run:  node serve.cjs   then open http://localhost:8080/  (needed for "install as app")
    (Python alternative: python3 -m http.server 8080)

On a phone: host this folder on any static web host (https), open it once, then use
"Add to Home screen" / "Install app". Everything (engine, 42k puzzles, lessons) is cached for offline use.
